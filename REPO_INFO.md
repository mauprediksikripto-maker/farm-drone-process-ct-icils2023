# Repository title and description (for GitHub / OSF)

**Repository name (slug):** `farm-drone-process-ct-icils2023`

**Title:** Same score, different process: Reset behaviour and computational thinking in ICILS 2023

**Short description (GitHub "About", ≤ 350 characters):**
Analysis code and aggregated results for a study of ICILS 2023 Farm Drone process data (40,921 students, 24 education systems): do resets and time in a block-based programming task predict computational thinking on a different, randomly assigned module beyond the task score? Python/Colab, JK2 jackknife, plausible values.

**Long description (OSF project / Zenodo record):**
This repository accompanies the manuscript "Same score, different process: Reset behaviour in block-based programming predicts computational thinking on a different task across 24 education systems". It contains a Google Colab notebook (and an identical Python script) that reproduces all estimates from the public ICILS 2023 International Database, Edition 2: construction of process indicators from the Farm Drone module (reset rate, time on task, rapid responses), stepwise weighted regressions with country fixed effects, JK2 jackknife standard errors and Rubin's rules over plausible values, exploratory analyses by task type and score level, system-level estimates, a balance check of the random module rotation, and robustness checks with gender and socio-economic background. Aggregated results, figures, and manuscript tables are included; ICILS microdata are not redistributed and must be obtained from IEA.
